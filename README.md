## Datasets Used
1. **[Crime Rate](https://data.wprdc.org/dataset/monthly-criminal-activity-dashboard/resource/bd41992a-987a-4cca-8798-fbe1cd946b07 ): This dataset measures reported criminal offenses by neighborhood, contributing to our metric by assessing personal safety and public security risks across the city.
2. **[Condemned Properties](https://data.wprdc.org/dataset/condemned-properties/resource/0a963f26-eb4b-4325-bbbc-3ddf6a871410 
): This dataset measures structures officially deemed unsafe, uninhabitable, or structurally unsound by the city, contributing to our metric by capturing severe physical blight and long-term housing instability.
3. **[311 Data]https://data.wprdc.org/datastore/dump/5202679a-d243-402e-b82a-63189995a942): This dataset measures non-emergency municipal service requests (such as potholes, illegal dumping, and broken streetlights) across Pittsburgh neighborhoods, contributing to our metric by quantifying day-to-day infrastructure neglect and neighborhood upkeep.
